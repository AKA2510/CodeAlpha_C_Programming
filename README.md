# CodeAlpha C Programming Projects

This repository contains three C programming tasks completed according to the CodeAlpha C Programming internship task sheet.

## Included Tasks

### Task 1 - Basic Calculator
Performs:
- Addition
- Subtraction
- Multiplication
- Division

A switch statement is used to select the operation.

### Task 2 - Matrix Operations
Includes:
- Matrix addition
- Matrix multiplication
- Matrix transpose

The program uses functions and two-dimensional arrays.

### Task 3 - Student Management System
Includes:
- Add student
- Display records
- Search student
- Update student
- Delete student

Student records are stored in a binary file so that the data remains available after the program is closed.

## How to Compile

Using GCC:

gcc calculator.c -o calculator
gcc matrix_operations.c -o matrix_operations
gcc student_management.c -o student_management

Then run the required program.

Windows:
calculator.exe
matrix_operations.exe
student_management.exe

Linux/macOS:
./calculator
./matrix_operations
./student_management

## Notes

The programs are intentionally written in a simple, readable style suitable for a beginner/intermediate C programming internship project. The implementation is original and does not copy a fixed online solution.
